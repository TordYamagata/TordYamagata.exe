# 🖥️ TordYamagata — Sobre Mim

Meu site pessoal desenvolvido com **HTML, CSS e JavaScript**, inspirado na interface clássica do **Windows 95/98**.

O projeto transforma meu portfólio em uma área de trabalho retrô, com janelas, ícones, barra de tarefas e menu iniciar.

## 💻 Tecnologias

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- 🪟 Janelas interativas
- 🖱️ Janelas arrastáveis
- 📁 Seção de projetos
- 👤 Sobre mim
- 💻 Habilidades
- 🌐 Link para o GitHub
- ▣ Terminal retrô
- 🪟 Menu iniciar
- ⏰ Relógio em tempo real
- ➖ Minimizar janelas
- ⬜ Maximizar janelas
- ❌ Fechar janelas

## 🎨 Estilo

O design foi inspirado nos antigos computadores e sistemas operacionais dos anos 90, principalmente na estética do **Windows 95/98**.
